# Balatro for RGDSplus R4.5

**本 Release 仅含适配包，不包含 Balatro 游戏本体、个人存档或完整测试包。**
请购买正版游戏，自行提供已验证兼容的 Windows `Balatro.exe`。

## 本版更新

- 修正双屏 CRT 效果的分屏采样和移动设备上的噪点计算。
- 修正计分火焰的显示精度与顶部面板范围。
- 调整手牌底板，保留手牌数量信息。
- 调整消耗牌按钮，避免相邻物品和屏幕边缘遮挡。
- 在保留减少动态效果设置的同时，恢复计分卡牌的抖动动画。
- 保持入口、运行时和存档标识不变。

## 安装与保留存档

1. 退出游戏，把整个 `Ports/BalatroDual/saves/` 复制到电脑备份。
   不要只备份 `save.jkr`，设置和各档位的解锁进度也需要保留。
2. 下载附件 `Balatro for RGDSplus.zip`，解压到 SD 卡游戏数据分区根目录，
   合并 `Ports` 文件夹。不要删除 `BalatroDual`，不要形成 `Ports/Ports/`。
3. 保留原有 `saves`、`gamedata` 和 `logs`。首次安装时，将正版 Windows
   `Balatro.exe` 放入 `Ports/BalatroDual/gamedata/Balatro.exe`。
4. 从 Ports 启动 **Balatro for RGDSplus**。首次离线组装期间请勿断电或拔卡。

支持已验证的 `1.0.1o-FULL / 1.0.1o / PROD_PC_Console` 本体。
存档继续位于 `Ports/BalatroDual/saves/love/balatro-dual/`。
若升级后存档异常，先退出并保留现场，再恢复整个 `saves/` 备份。
GitHub 自动生成的 Source code 压缩包不是 SD 卡安装包。
